# QQ 邮箱

QQ 邮箱是 Codex 的第三方邮件应用，非腾讯官方客户端。你可以在 Codex 中指定读取某封邮件或某个分组，并管理本地收录、分类规则和提醒。目前支持 QQ 邮箱和 Foxmail，通过 IMAP 只读连接；通用 IMAP 接入是扩展方向，暂不支持配置其他邮箱服务商。

在 Mac 登录期间每两分钟检查 QQ 邮箱收件箱。不标记已读，也不移动邮件。分组保存在本机，不会在 QQ 邮箱中创建文件夹。首次连接只收录之后到达的邮件。

## 启用

1. 在 QQ 邮箱设置中启用 IMAP/SMTP，生成客户端授权码（不是 QQ 登录密码）。
2. 在 Codex 打开「QQ 邮箱 → 设置 → 打开本机授权」。
3. 在 Mac 授权弹窗输入 QQ 邮箱或 Foxmail 地址及客户端授权码。授权码以密码样式显示，不会发送给 Codex。该操作先验证邮箱，再启动后台监听。
4. 运行 `/usr/bin/python3 watch.py test-notification` 测试通知；若没显示，检查 macOS 的通知权限与专注模式。在插件聊天中说「查看邮箱监听状态」确认同步。

## 管理

- 邮件列表与详情优先显示内置的品牌图标；没有图标的发件人使用固定颜色和首字符，未知发件人显示信封。头像仅供辨认，不表示身份认证，也不请求外部图片。
- 已加载的收件箱列表和分页位置会保存在本机，下次打开自动恢复。需要更新时点「重新加载」，或继续加载更早的邮件。缓存只包含列表邮件头，不保存正文。

- 「最近邮件」先加载最新 10 封，列表底部可继续加载更早的 10 封，或用「重新加载」回到最新一批。浏览不会标记已读、收录历史邮件、改变同步进度或触发提醒。点「建规则」可带入发件地址。
- 可按主题、正文和收件时间范围匹配。时间字段按本机时区填写，以服务器记录的收件时间判断。正文条件只在其他条件满足时读取原始邮件的前 256 KiB，在本机提取正文文字匹配；不保存正文，也不打开附件。
- 「刷新状态」显示最近一次页面刷新时间及成功或失败；它与后台最近成功同步时间不同。
- 「历史回放」可按最近封数或收件时间段预览，每次最多 100 封。确认后只收录未收录的邮件，不发提醒、不改变监听进度。范围过大时请分段。
- 点击邮件主题进入独立阅读视图。默认保留原文排版和内嵌图片，有可读文本时可切换「纯文本」。远程图片默认不加载，可仅为当前邮件开启。从分组或历史回放进入时，返回会保留原列表和滚动位置。预览不会执行脚本、打开附件或标记已读。
- 在邮件详情或分组收录列表点「复制引用」，粘贴到同一台 Mac 上启用了 QQ 邮箱的 Codex 对话即可查询。只贴引用时默认查看邮件头或分组列表；要读取正文，可在引用后加上「总结这封邮件」。分组引用指向当前收录，改名仍有效，删除即失效。引用不是公开链接，复制本身不会对外发送邮件；在对话中查询时，相应的邮件数据会提供给当前对话。
- 分组列表右侧可直接复制单封邮件引用，顶部「复制分组引用」复制整组。Agent 读取正文时默认压缩多余空白；需要原样的空格和换行时，可要求 Agent 使用 `raw_body=true`。页面预览保持原有排版。

- 在 Codex 侧边栏打开「QQ 邮箱」，可查看邮箱是否已授权、后台是否启动、最近同步、各组收录量和提醒设置。找不到入口时，在启用了本插件的聊天里说「打开 QQ 邮箱状态页」。
- 在「设置 → 分组管理」可新建、查看、改名或删除分组，也可快速开关提醒。规则只在分组编辑器里显示，按需添加条件，和分组一起保存。
- 删除分组会移除该组规则，并将本机收录移到「未分类」，不删除邮箱原件。「未分类」不能改名或删除。

- 同一组命中任一规则即可，同一条规则内条件需同时满足。默认保留原规则顺序；也可在「匹配顺序」明确切换为按组优先，第一条命中生效。旧收录不会因规则变动而重新分类。发件人字段可以伪造，不适合用作安全凭证。
- 桌面通知只显示分组名和新邮件数量。Mac 休眠时不轮询，唤醒后补查；退出 Codex 不影响已启动的监听。关闭某组提醒不影响收录。
- 运行 `/usr/bin/python3 watch.py stop` 停止监听。「打开本机授权」可以恢复监听或更换同一邮箱的授权码。此包支持单个 QQ 邮箱。服务端重置邮件编号时会暂停收录，不会擅自跳过或导入整箱邮件。
- 设置、授权码与收录记录留在 `~/Library/Application Support/QQ Mail Watch`，目录仅对本机当前账户开放。授权码以本机权限保护的文件保存，不是系统钥匙串；停用时可在 QQ 邮箱撤销授权码。主动在 Codex 查询邮件列表会把返回的邮件头提供给当前聊天。
- 如尚未安装账号内插件，也可通过 Codex 的本地插件市场，添加本目录为插件来源。需使用具备 `/usr/bin/python3`（3.9 或更新）的 Mac。
